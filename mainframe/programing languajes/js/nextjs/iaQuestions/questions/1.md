# archivos y funciones  especiales de Pages Route

📁 Archivos especiales en pages/
1️⃣ _app.tsx



* Envuelve todas las páginas
* Ideal para layouts globales y providers
* Corre en cliente y servidor

2️⃣ _document.tsx

* Personaliza <html>, <head> y <body>
* Solo se ejecuta en el servidor

3️⃣ _error.tsx

Permite personalizar la página de error general.

pages/_error.tsx

Ejemplo:

```tsx
export default function Error({ statusCode }) {
  return (
    <p>
      {statusCode
        ? `Error ${statusCode}`
        : 'Error en el cliente'}
    </p>
  )
}
```
Se usa cuando ocurre un error 500 o similar.

4️⃣ 404.tsx

Página personalizada para rutas que no existen.

pages/404.tsx

Ejemplo:

export default function NotFound() {
  return <h1>404 - Página no encontrada</h1>
}
5️⃣ 500.tsx

Página personalizada para errores del servidor.

pages/500.tsx

🔥 Archivos relacionados con datos (no son archivos especiales pero sí funciones especiales)

Dentro de cualquier página puedes usar:

getStaticProps

Generación estática (SSG)

getServerSideProps

Renderizado en servidor (SSR)

getStaticPaths

Para rutas dinámicas estáticas

 


Resumen completo (Pages Router)

Dentro de pages/ puedes tener:

```bash
pages/
├── _app.tsx
├── _document.tsx
├── _error.tsx
├── 404.tsx
├── 500.tsx
├── index.tsx
├── about.tsx
└── api/
```
